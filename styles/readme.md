
#### 1) What is the difference between `null` and `undefined`?
answere: - null means an intentional empty value, while undefined means a variable is declared but not assigned a value.

#### 2) What is the use of the `map()` function in JavaScript? How is it different from `forEach()`?
answer: - map() creates and returns a new transformed array, while forEach() only executes a function for each element without returning a new array.

#### 3) What is the difference between `==` and `===`?
answer:-  == compares values with type conversion, while === compares both value and type strictly without conversion.

#### 4) What is the significance of `async`/`await` in fetching API data?
answer:-  async/await makes asynchronous API calls easier to read and manage by writing them in a synchronous-like structure.

#### 5) Explain the concept of Scope in JavaScript (Global, Function, Block).
answer:- Scope defines where variables are accessible: Global scope is accessible everywhere, Function scope inside a function, and Block scope inside {} only.
